# PWA_Project

個人的 PWA（可離線、可加入手機主畫面的網頁應用）集中放置處，每個應用一個子資料夾。

| 應用 | 網址 |
|---|---|
| 台灣股票監控（監控清單、停利停損警示、歷史股價走勢） | https://blackjackx7.github.io/PWA_Project/stock/ |

## 手機安裝

1. 用 Chrome（Android）或 Safari（iOS）開啟上面的網址。
2. Android：選單 →「安裝應用程式」；iOS：分享 →「加入主畫面」。
3. 之後一律從主畫面圖示開啟（iOS 上主畫面與 Safari 分頁的資料是分開的）。

## 搬移資料

資料只存在各自的瀏覽器，不會上傳。電腦版按「匯出設定」→ 把 JSON 傳到手機 → 手機版按「匯入設定」。畫面上會顯示上次匯出備份的時間。
